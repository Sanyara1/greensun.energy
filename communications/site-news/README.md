# Новости GSun: первый предпросмотр

24.10.2026. PREVIEW_ONLY. Не опубликовано, расписание не подключено.

## Состав

build_news_preview.py создаёт список материалов, статью digital-engineer, CSS, редакционную SVG-иллюстрацию и review.json с хешами. Зависимости: Python 3, стандартная библиотека. Сеть и секреты не используются. Выходной каталог обязан отсутствовать.

Первый материал: «Зачем солнечной станции цифровой инженер». Это направление разработки, не анонс готового продукта. Новый текст требует согласования владельцем; старое согласование ноябрьских постов его не покрывает. Источники и их commit находятся в review.json, внутренние ссылки не выводятся в статью.

## Локальный просмотр на Mac

Скачать скрипт, затем:

```sh
python3 ~/Downloads/build_news_preview.py --output ~/Downloads/gsun-news-preview-v1
open ~/Downloads/gsun-news-preview-v1/index.html
```

Не запускать с выходом в /var/www и не копировать review.json в публичную папку. noindex — не контроль доступа. Предпросмотр предназначен для локального открытия, а не для публичного адреса.

## Проверки

PASS: относительные ссылки и иллюстрация существуют; хеши совпадают; запрет перезаписи; noindex на обеих страницах; approval=null и publishing_enabled=false. Визуальная проверка браузером в среде сборки не выполнена: отсутствует исполняемый Chromium. Требуется просмотр desktop/mobile владельцем.

## Перед публикацией

1. Согласовать текст и оформление. Сверить свежесть исходных утверждений и право публичного раскрытия.
2. Снять копию актуальных файлов VPS и проверить nginx/root. index.html в этой ветке — старая версия сайта, не источник для замены главной.
3. Подготовить отдельную установку только /news/ с резервированием и откатом. Добавить ссылку в актуальную навигацию отдельным проверяемым изменением.
4. Для публичной сборки убрать draft/noindex, задать фактическую дату публикации, canonical и OG, добавить URL в существующую sitemap. Не обещать немедленную индексацию.
5. Только после HTTP-проверки опубликованной статьи подготовить точные TG/MAX анонсы и их отдельные квитанции. Ноябрьский план V6 и его approval не изменять.

Автоматический сайт-публикатор, анонсы и расписание в эту итерацию не входят. Следующий результат: одна согласованная статья на сайте; затем исполнитель с проверкой хеша согласования и защитой от повторов.

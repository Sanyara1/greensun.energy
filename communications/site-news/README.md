## Локальный просмотр

Из корня этой ветки репозитория:

```sh
python3 communications/site-news/build_news_preview.py \
  --output "$HOME/Downloads/gsun-news-candidate-20261025"
open "$HOME/Downloads/gsun-news-candidate-20261025/news/index.html"
```

Выходной каталог должен отсутствовать. На Linux вместо `open` можно открыть HTML браузером или выполнить `python3 -m http.server 8765 --bind 127.0.0.1 --directory /private/path/gsun-news-candidate-20261025` и перейти на `http://127.0.0.1:8765/news/`. Не размещать preview на публичном сервере: noindex не является защитой доступа.

Сборщик использует Python 3 (3.8+) и стандартную библиотеку; зависимости и запросы в сеть для сборки отсутствуют. Рядом со скриптом должны находиться `article.json` и каталог `assets/`, включая готовый `cover-og.png`. В отличие от первоначального скрипта, скачивания одного .py больше недостаточно. Для готового архивного предпросмотра сборка не нужна: открыть `news/index.html` после распаковки.

## Состав и режимы

- `article.json` — редакционный текст и ссылки на исходные записи.
- `assets/` — изолированный CSS, две SVG-иллюстрации, PNG для Open Graph 1200×630, favicon. Чужие CSS/JS не загружаются.
- Результат: `news/index.html`, `news/digital-engineer/index.html`, `news/assets/*`.
- `review.json` находится **вне** news, содержит хеши и статус. Его не устанавливать на сайт.
- Preview по умолчанию: баннер «не опубликовано», `noindex,nofollow`, отсутствуют canonical/OG/публичная дата/sitemap, `approval=null`.
- Public: отдельная команда с записью решения владельца и хешем точной версии. Canonical и og:url используют конечные URL с `/`; og:type=article у статьи, website у списка; PNG с абсолютным URL; дата в `<time>`, article:published_time и sitemap. Состояние сборки `PUBLIC_BUILD_NOT_DEPLOYED`; публикация этим не подтверждается.
- `/news/sitemap.xml` возникает только в публичной сборке. Существующие корневые robots/sitemap не перезаписываются; способ подключения — INSTALL.md.

Новая статья и её раскрытие требуют отдельного решения владельца. `approval.example.json` намеренно НЕ содержит согласования. Gate защищает от случайной сборки и устаревшего хеша; он не удостоверяет личность подписанта. Порядок подтверждения реального решения остаётся операторским.

## Проверки

```sh
python3 -m unittest discover -s communications/site-news -p 'test_*.py' -v
```

Для повторного браузерного QA дополнительно нужен установленный Playwright и Chromium (они не нужны для сборки). Запуск:

```sh
CHROMIUM_PATH=/path/to/chromium node communications/site-news/qa_browser.cjs \
  /private/path/gsun-news-candidate-20261025 /private/path/qa-output
```

`NODE_PATH` при необходимости указывает на установленный пакет Playwright. Скрипт поднимает локальный сервер на 127.0.0.1, проверяет две страницы на пяти ширинах, переходы, Tab/Enter, загрузку иллюстраций, границы SVG и отсутствие горизонтальной прокрутки. Снимки экрана и browser-results.json сохраняются отдельно. Мобильная проверка выполнена эмуляцией Chromium; Safari на физическом iPhone не проверен.

SVG — исходные редактируемые векторные иллюстрации. PNG получен скриншотом `cover.svg` в Chromium при viewport 1200×630; внешние изображения, шрифты и генераторы не требуются. При изменении SVG обновить PNG и повторить QA — изменится candidate_sha256 и потребуется новое согласование.
